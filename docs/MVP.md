# Conversational LabMate MVP

The primary flow is PDF → Start conversation → spoken overview and handout precautions → continuous spoken questions and answers. Typing is optional. There are no app checkboxes, grading screens, or transcript confirmation. The human explicitly requested this direction and asked D to complete other roles and skip tests. B's earlier harness contributions are retained; D implemented the missing experience and integration.

Use a PDF with selectable text, up to 5 MiB, 25 pages and 24,000 extracted characters. The PDF is parsed in a resource-limited worker and is not saved by the app. Conversation and handout text live in the page's memory and are sent to xAI for answers. ElevenLabs handles transcription and speech. Precautions are exact quotes validated against the uploaded page; page buttons show the extracted source. The document is user supplied, not independently verified. LabMate does not invent missing safety instructions or replace the course protocol or supervisor.

After starting, LabMate reads the brief and precautions, then listens. Speech ends after a 2.2-second pause. The next listening turn starts after the answer is spoken. End conversation, say “stop listening,” or leave the foreground to close the session. Each recording is limited to 29 seconds. This is turn-based voice; interrupting by talking over playback is not implemented. Keep the page visible. Typed questions are available under Type instead once voice has ended. Emergency questions receive fixed escalation text and voice ends after that response.

Use Node 24, npm ci, npm run build, then supply runtime secrets and npm start. For local standalone operation use `HOSTNAME=127.0.0.1 PORT=3107 node --env-file=.env.local .next/standalone/server.js`. Development mode loads .env.local automatically. The build deliberately excludes local .env files.

Live setup needs server-only XAI_API_KEY, XAI_MODEL, the four ELEVENLABS settings, APP_MODE=live, REVIEW_SUPERVISED_DEMO=true, REVIEW_MAX_PROVIDER_CALLS=30, ENABLE_VOICE=true, VOICE_SUPERVISED_DEMO=true, and VOICE_MAX_PROVIDER_CALLS=30. Only a supervised single process is supported. Voice allows 20 calls/minute, two concurrently, and the paid-attempt cap; restarting resets in-memory allowances. Public/serverless hosting needs a distributed limiter. Keep provider credit limits in the vendors' dashboards.

The prior text-review endpoint and local NIST source pack remain for compatibility. The main conversational flow uses the uploaded handout as context. Snowflake and camera are excluded. No sponsor eligibility, public deployment, or human microphone pass is implied. Exact code, compilation and live diagnostic evidence are in docs/STATUS.md and coordination/status/D.json. Test suites remain skipped at the human's request.

PDF extraction uses pinned [unpdf](https://github.com/unjs/unpdf), with page and text limits checked before returning data. Bundled workers receive an object containing transferred file bytes, preserving them when Turbopack adds its worker runtime metadata.
